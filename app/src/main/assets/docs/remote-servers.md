# 连接与同步：SFTP/FTP 工作区同步 (Remote Servers & Sync)

让手机通过 SFTP / FTP / 本地镜像把工作区目录与远程或本地目录**同步**。进入“设置” -> 「运行环境」->「连接与同步」，页面底部悬浮胶囊 tab 栏分 4 个标签页。

> **本页与「容器与镜像」页的分工**：本页只负责连接通道与文件同步（SFTP / FTP 通道、挂载目录、内置 FTP、同步规则）。若你想让 AI 把**远程服务器作为执行后端**（即「远程工作区」：命令、文件、终端都直接在远程机器上运行，`~/workspace` 映射到远程路径），请到「设置」->「容器与镜像」页新建「远程 SSH」镜像，选择本页建好的 SFTP 通道并填写远程工作区路径（详见 `container-image.md` 第 2 节）。

## 1. 连接配置 (Tab 1)
点击右上角「+」填写连接通道参数：
*   **协议类型**：顶部分段选择器三选一：`SFTP`（默认端口 22）/ `FTP`（默认端口 21）/ `本地`（LOCAL，端口置 0）。
*   **连接名称** / **通道名称**：别名（本地通道提示如“内部存储镜像”）。
*   **主机地址**：IP 或域名；本地通道则填“内部存储目标目录”（如 `/storage/emulated/0/AICode/projects`）。
*   **端口 / 用户名 / 认证方式**：SFTP/FTP 必填。认证方式二选一：**密码**（默认，密码框可切换可见性）或 **密钥**（从「SSH 密钥」页已添加的登录密钥中选择，加密私钥可填口令）。本地通道不显示这些字段，工作区会单向同步到该目录，供只能访问普通目录的 App 使用。
*   **测试连通性 / 测试目录**：保存前可点击测试（本地通道测试目录可达）。

*   **SSH 密钥页（顶栏钥匙图标）**：底部双 tab——**密钥** tab 管理登录密钥库：点右上角「+」从文件选择器选择私钥文件（复制到应用私有目录并解析公钥指纹，加密私钥显示「需口令」），左滑删除；**指纹** tab 展示已保存的主机指纹：首次连接（或测试连通性）时需确认服务器主机指纹——弹窗内展示密钥类型与 `SHA256:` 指纹，确认「信任并连接」后保存到应用私有配置，后续连接直接放行；已保存指纹变化时会再次要求确认。左滑可删除，删除后下次连接重新确认。

## 2. 挂载目录 (Tab 2)
点击右上角「+」选择一个已建好的连接通道，建立映射关系：
*   **关联远程连接通道**：下拉选择连接。
*   **远程目标目录 / 镜像目标子目录**：右侧文件夹图标可打开**远程目录浏览器**逐级浏览选择；本地通道填根目录下子目录，通常保持 `/`。
*   **映射到本地工作区**：下拉选择本地工作区（需先在侧边栏创建）。
*   **应用启动时自动连接**：开关，开启后**跟随当前工作区**——App 启动（工作区就绪）或切换工作区时，自动连接映射到当前工作区的挂载并同步；同时自动断开其它工作区的挂载（含手动连接的）。连接失败会按退避间隔持续重试直到成功，关闭开关即停止。
*   **重复检测**：保存时若已存在相同「通道 + 远程目录 + 工作区」组合的挂载（编辑自身除外），会提示「该挂载已存在」并拦截保存。
*   连接后卡片提供「断开连接」「上传全部 / 同步全部」「下载全部」（本地通道无下载）与「连接并同步」；列表行左滑可删除。

> **同步方向（重要）**：工作区同步是**单向**的——自动同步只把本地工作区的改动推送到远程（监听本地文件增删改，含删除；连接建立时自动全量上传一次），远程目录的变化**不会**自动拉取。需要把远程文件拉到本地时，手动点「下载全部」；该操作是**全量覆盖式**拉取，会覆盖本地同名文件（不删除本地多余文件），本地未提交的修改可能被覆盖，请谨慎使用。本地（LOCAL）通道仅支持上传方向，无下载。

> **连接与保活**：SFTP/FTP 连接超时为 15 秒，主机不可达时快速报错而非无限等待。已连接的挂载每 30 秒探活一次，检测到断线会自动按 5s → 10s → 20s → 40s → 60s 退避重连并恢复同步，无需手动干预。自动连接**跟随当前工作区**（切换工作区会断开其它工作区的挂载）；非当前工作区的挂载需要时手动「连接并同步」。本地（LOCAL）通道无网络连接，不参与探活与重连。

## 3. 内置FTP (Tab 3) - 内置 FTP 服务端
手机端内置轻量级 FTP 服务器，方便电脑端远程管理手机工作区：
*   **使用说明**：手机与电脑需连同一 WiFi；开启后在电脑文件资源管理器或 FileZilla 地址栏访问显示的 FTP 地址（如 `ftp://192.168.1.100:2121`）。
*   **服务开关**：开启后显示“运行中: $serverUrl”（点击地址可复制），关闭显示“服务未开启”。
*   **服务参数配置**：监听端口、登录用户名、登录密码（开匿时禁用）、「允许匿名访问」开关、「开机自启」开关，底部「保存配置」按钮。
*   连接后可访问并管理手机 `projects/` 目录下的全部代码项目。

## 4. 同步设置 (Tab 4)
配置底层文件同步引擎的行为，两组设置一次保存：
*   **遵循 .gitignore 规则**：开关，开启后自动读取项目根目录 `.gitignore` 进行过滤。
*   **单次最大同步队列数量**：防止突发大量文件修改同时请求服务端断连，超过此数量的操作排队按批次执行（批次间稍作停顿）。
*   引擎始终内置忽略常见构建/缓存目录（如 `node_modules`、`.git`、`build`、`dist` 等），无需手动配置。
*   改动后点击底部「保存设置」一次性生效。
