# 外观主题、背景图与语言

“设置”首页点击「外观主题」「背景图」或「语言」会弹出底部窗口进行选择，选择后立即生效并持久化保存。

## 外观主题
*   **跟随系统**：跟随系统当前的明暗主题。
*   **深色**：固定使用深色主题。
*   **浅色**：固定使用浅色主题。

## 自定义背景图
在「背景图」弹窗中可以设置一张全局背景图：
*   **选择图片**：从系统相册选择一张图片作为 App 全局背景，叠加在所有页面内容之上（水印效果，不拦截触摸），终端页保持纯黑底不显示背景。
*   **透明度**：滑块显示 0%～100% 完整刻度，实际生效范围映射为 0%～20%（0% 完全透明、100% 对应 20%），保证文字可读；默认 15%。拖动实时生效。
*   **移除背景**：删除背景图，恢复默认纯色背景。背景图文件保存在应用私有目录，不随备份导出。

## 语言
*   **跟随系统**：跟随系统 Locale。
*   **已支持语言列表**：直接选中需要的语言。
